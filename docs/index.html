How it works

Claude Code can run a command on certain events, called hooks. Sua Vez registers itself for six of them, from a prompt being submitted to a session ending.

  1. Claude Code runs suavez hook and passes it the event.
  2. That process writes a small file for the session and pokes the tray.
  3. The tray rereads the files and repaints the bubble.

The hook prints nothing and always exits cleanly, so a failure in Sua Vez never stops Claude. When it edits settings.json, it only touches its own entries. Your other hooks and settings keep their place.

Disconnect any time from the menu, or with suavez uninstall in a terminal.
